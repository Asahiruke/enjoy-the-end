# Enjoy the End

A text-first apocalypse life simulator focused on preparation, home management, survival, weather, inventory, NPC routines, and gradual collapse.

## Current build

Prototype 0.11

## Play

The repository deploys the current prototype to GitHub Pages automatically from the `main` branch.

## Development direction

- Character creation and persistent saves
- Room-based interactions and workstations
- Home storage, containers, volume and weight
- Weather and World Tick framework
- NPC/pet schedule framework
- Carry accessibility and vehicle cargo rules
- Planned expedition/outdoor action system

The project is currently an experimental prototype.
